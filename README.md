# Group4_GlobalDiversificationInvestments
This repository is used for documenting the process of creating a system for our class project. The system is a web-based application allowing users to learn about diversifying an investment portfolio, or gain analytical insight on current investment portfolios (specifically global diversification).


Team Members: Mandeep, Anita, Shania

All team members contribute to: 


 • Brainstorming and refining features for the system.
 
 • Collecting and analyzing user and system requirements.
 
 • Writing and maintaining technical and project documentation.
 
 • Implementing features, fixing bugs, and testing components.
 
 • Using Git/GitHub to manage code changes and branches.
 
 • Reviewing teammates’ pull requests to ensure quality and consistency.
 
 • Ensuring features work as intended and resolving issues.
 
 • Tracking progress, managing tasks, and meeting deadlines.



Instructions on how to clone the project, and switch to its local directory:
git clone https://github.com/Mandeepkaur8806/Group4_GlobalDiversificationInvestment

Branching and Workflow Guidelines: When working on the project, your work will be on a branch and any changes must be integrated back into the main branch through merging. Changes on a branch must be approved by all other collaborators before through a pull request.
